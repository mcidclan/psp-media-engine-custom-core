## PSP Media Engine Audio: Local FIFO Feed
This code aims to demonstrate filling the audio FIFO from the media engine on a minimal setup. As an example, it simply generates white noise.

## Usage
Build it with CMake, then copy the EBOOT.PBP into a folder within the GAME directory.
